    FAQ

    Questions, answered.

    What is NovaGit?

    NovaGit is a Windows desktop client with its own native .novagit repository format, as well as a compatibility mode for existing Git repositories.

    What does native mode use?

    Native NovaGit repositories use SHA-256 IDs and compressed blob, tree, and commit objects. They include editable .novaignore and .novaattributes files.

    Can I use GitHub with NovaGit?

    GitHub uses Git's format and protocol, so use NovaGit's Git compatibility mode for GitHub remotes.
